5.3.5. Multi-Agent
To explore multi-agent collaboration on complex tasks, we conduct preliminary experiments
with DeepSeek-V4.1-Flash using DeepSeek Harness’s Agent Team mode.
Multi-Agent Harnesses. We use DeepSeek Harness in Agent Team mode, where a lead agent
can asynchronously create named, persistent teammates by default through spawn_teammate.
Each receives a delegated task and starts in either fresh mode without lead history or fork
mode with a one-time snapshot of the lead’s completed turns. All agents share one repository
checkout, making edits immediately visible to one another.
Agents communicate through a durable peer mailbox. A message sent through send_message
reaches a running teammate at its next step boundary, starts a new turn for an idle teammate,
or resumes an inactive teammate. Across each teammate’s task lifecycle, the lead monitors
runtime status with list_agents and waits for status, mailbox, or shared-task changes with
wait_agent. Task ownership, dependencies, and advisory write scopes are maintained on
a shared task board (using the four team_task_* tools with revision checks on updates).
