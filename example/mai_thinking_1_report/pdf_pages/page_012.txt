2.4 Pre‐training Data
MAI-Base-1 is trained on a mixture of publicly available and licensed human-generated data. We compile
a high-quality, diverse set of pre-training data covering web, public GitHub code, books, academic papers,
news, multilingual text, and domain-specific materials. We choose not to use language-model-generated
synthetic data for pre-training, and we make an effort to avoid and remove AI-generated content within
collected data sources (Appendix B).
All of our pre-training data is processed in-house from one of our base sources: HTML and PDFs from
the web, books and journals, and public GitHub code. We do not use any open source training datasets,
and we exclude common machine learning repositories from our web data, such as huggingface.co and
